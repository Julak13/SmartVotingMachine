Voting Machine Updater

Install the latest firmware from this page. No Arduino software needed.

Install update v1.1.1

This browser can't talk to USB devices. Open this page in Google Chrome or Microsoft Edge on a laptop or desktop computer (not a phone). This page must be opened over https:// to use USB.
Takes about 30 seconds. Keep the cable plugged in until it reaches 100%.

⚠ Do NOT erase

During installation you will see a box called "Erase device". Leave it unticked. Ticking it deletes every registered voter, candidate and vote on the machine.

Step by step

  1. Plug the voting machine's ESP32 board into the laptop with a USB data cable (some cables only charge; if nothing is detected, try another cable).
  2. Click Connect & install above. A list of ports appears — choose the one that says CP210x, CH340 or USB Serial, then click Connect.
  3. Click Install. When asked about erasing, leave "Erase device" unticked, then continue.
  4. Wait until it shows the install is complete.
  5. Press the EN (reset) button on the board, or unplug and replug it. The machine plays its ready chime and shows System Ready.
  6. Check: on the dashboard, open Settings → Device. It should say Firmware v1.1.1.

If it gets stuck on "Connecting" or fails to start

This board needs a little help to enter update mode. Click Install again and hold the BOOT button on the ESP32 board; let go as soon as the progress starts moving.

Before the first update (one time)

  • Use Chrome or Edge on Windows, Mac or Linux. Phones and iPads cannot do this.
  • If no port appears in the list, install the USB driver for the board's chip, then try again:
    • CH340 driver (WCH)
    • CP210x driver (Silicon Labs)
  • Close the Arduino IDE's Serial Monitor (or any program using the port) before installing.

What's new

  • v1.1.1: the card reader works exactly as in v1.0 again. (v1.1.0 changed how the reader is set up, and on the real machine that stopped it responding.)
  • The machine no longer freezes if a voter walks away on the candidate screen (30-second timeout).
  • Fingerprints: a smudged touch is retried instead of rejected; a finger already registered to someone else is refused at enrollment.
  • "Card already registered to name" tells you exactly which voter to delete.
  • Deleting a voter also erases their fingerprint; leftovers from older versions are cleaned up once.
  • New Settings tab: send results to Telegram (automatically when the election stops), connect to an internet Wi-Fi, and see device health.
  • The dashboard can be added to a phone's home screen like an app.

Previous version (v1.0) — only if you need to go back

Installs the original firmware. It keeps the voters and candidates (same rule: leave "Erase device" unticked), but it brings back the old problems: the screen can freeze if a voter walks away, smudged fingerprints are rejected, and there is no Telegram or Settings tab.
